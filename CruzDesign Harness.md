Palette × Style — two independent axes

# Any colour. Any style. The same standard.

Colour and style are separate choices. Pick a *palette* and, independently, a *style* above — the whole page recomposes. “Copper on Champagne” is only a palette; “Skeuomorphic” or “Liquid Glass” is the surface treatment. Every cell of the matrix keeps the same components, the same screens and the same gate. That is CruzDesign: a quality bar and a process, never a look.

## The two it won't bend on

Fail either and nothing else saves it — in any colour, in any style.

**Reduction to the essential**

One obvious action per screen; everything else recedes. Simplicity from resolving complexity, not hiding it.

**Honesty**

Material reads as what it is, lit from one source — gloss only where a style earns it; and honesty to the person: right defaults, truthful copy, no dark patterns.

**One accent**

A single earned accent per world — whatever the palette — never two competing, never a slab.

**The next step, in view**

No dead scroll. The one thing to do now sits where the eye lands, whatever the skin.

**Inevitability**

It should feel like the only way it could be — the mark of done in every style.

## The gate — constant across every cell of the matrix

Changing the palette or the style doesn't move a single line of this. Every screen, in every colour and every style, is held to it before it ships.

- Pass**Reduction / one action** — dashboard and record lead with a single primary action.
- Pass**Honesty of material** — each style's surfaces read true; one light source; gloss only where the idiom earns it.
- Pass**One accent** — a single earned accent per world; the brand mark's navy is the logo, not a second UI accent.
- Pass**Typography** — display + text with one job each, one scale, tabular numerals.
- Pass**Tokens, not literals** — colour and material are token sets; the page recomposes from two variable groups (guarded by a test).
- Pass**Next step in view** — sticky nav on long pages; primary action where the eye lands.
- Pass**States crafted** — hover / focus / disabled / loading / empty / error all designed, in every material.
- Refine**Corners** — related radii today; move to continuous curvature for true inevitability.
- Refine**Motion** — add spatial transitions (esp. reschedule) so nothing "disappears".
- Fix**It just works** — reschedule must pick from real availability and confirm where it lands.
